# results

Snapshot of the full 139-cell run, so the findings can be read without re-running anything.

| File | Contents |
|---|---|
| `summary_fleet.csv` | fleet-relative re-scoring of all 139 cells: best parametric law, runner-up and ΔBIC, misfit and knee z-scores, reasons, flag, priority |
| `report_llm.md` | the report written by the LLM (Llama 3.1 8B) in the same run, verbatim |

A fresh run writes the same files (and per-cell plots and fit tables) to `agent_outputs/`.
